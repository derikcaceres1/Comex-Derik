COMEX NM v2

Pipeline da Nova Metodologia refatorado — standalone, filtros explícitos, histórico append-only, upload opt-in.
Documentação técnica detalhada: REFATORACAO_NM_V2.html

Pré-requisitos

  • Python 3.10+
  • Pacotes: pandas, numpy, statsmodels, pyyaml, openpyxl, pyarrow, requests, beautifulsoup4
  • Arquivos de referência presentes no repositório: library/IDS_comex.xlsx e NM/serie_temporal/data-contract.yaml
  • Dados históricos em disco: NM/dados/BRA/database/historical.parquet (Brasil) e NM/dados/EUR/database/historical.parquet (Itália / países EUR)
Working directory. Todos os comandos abaixo devem ser executados a partir da pasta comex/ (raiz do projeto, onde ficam as pastas NM/, library/, etc.). O v2 resolve todos os paths com base na sua própria localização — não depende do CWD, mas é boa prática manter consistência.

Como rodar — Desenvolvimento (sem upload)

Por padrão os scripts rodam em modo desenvolvimento: leem/escrevem apenas em disco, nunca enviam dados à plataforma.

▶ Execução completa (com coleta de dados novos)

# Brasil — faz download do portal gov.br + filtros + cálculo
python NM\serie_temporal\COMEX_BRA\COMEX_BRA_NM_v2.py

# Itália — usa o historical.parquet EUR já em disco
python NM\serie_temporal\COMEX_ITA\COMEX_ITA_NM_v2.py

▶ Rerun rápido (pula a coleta, usa o histórico que já está em disco)

# Útil para re-testar filtros ou cálculo sem re-fazer o download (~10 min de diferença)
python NM\serie_temporal\tests\BRA\rerun_calc_v2.py
python NM\serie_temporal\tests\ITA\rerun_calc_v2.py

▶ Comparar gold v2 com gold v1 (validação)

python NM\serie_temporal\tests\BRA\comparar_gold_v1_v2.py
python NM\serie_temporal\tests\ITA\comparar_gold_v1_v2_ita.py

▶ Rodar tudo de uma vez (rerun + comparação)

powershell -ExecutionPolicy Bypass -File "NM\serie_temporal\tests\run_all.ps1"

Como habilitar upload (produção)

O upload tem dois bloqueios por segurança:

  1. NMConfig.allow_upload — padrão False
  2. Flag developing=True — bloqueia mesmo se allow_upload=True

Para subir à plataforma, edite o main() do arquivo do país:

# COMEX_BRA_NM_v2.py — trecho do main()
pipeline = COMEX_BRA_NM_v2(
    start_date=start,
    developing=False,                          # ← desliga modo dev
    config=NMConfig(allow_upload=True)          # ← habilita upload
)
pipeline.run()                                   # ← sem skip_phases
Atenção: com developing=False o pipeline tentará ler/gravar no Azure Storage. Garanta que as credenciais estejam configuradas antes.

Adicionar um novo país EUR (DEU, FRA, NLD…)

Copie COMEX_ITA_NM_v2.py, renomeie e troque 3 linhas:

class COMEX_DEU_NM_v2(ComexPipelineNMv2):
    def __init__(self, ...):
        super().__init__(
            iso_code="DEU",       # ← trocar
            iso_database="EUR",   # ← manter para países EUR
            ...
        )
    def _get_country_name(self) -> str:
        return "Alemanha"       # ← trocar

O _country_specific_treatment é idêntico para todos os países EUR — não precisa mudar.
